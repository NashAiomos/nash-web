花一年时间写的书

06/01/2024
#Chinese & 中文 #Experience #IC

2023 年，我花了一整年写《ConstellationBook》。说起来，我一开始也没打算写书，就是自己在学 Internet Computer，读了一些白皮书，也翻了不少论坛里的讨论，觉得有些东西值得记下来。

有一次，我跟一个朋友聊起 Internet Computer 的架构，顺口说了句，等我把笔记整理好了就发给你。说这话的时候，我还觉得整理笔记能花多久。结果前前后后弄了一年。

这一年里当然也有拖着没写的时候。有些内容，刚记下来的时候觉得自己已经懂了，隔一阵子再看，发现还有地方说不清楚。自己看笔记，几个关键词就能想起来当时在说什么。可朋友拿到手里，看到同样几个词，可能第一句就要问我，这跟前面讲的有什么关系？想到这里，我就得回去翻资料，再想想从哪儿开始讲比较顺。

后来书大致分成了两部分。前面讲 Internet Computer 的一些原理，后面讲怎么动手开发。我希望读的人可以先搞明白自己在用什么，等真想试一试的时候，也知道第一步该做什么。现在回想起来，决定哪些东西要先讲，就已经让我重新学了一遍。有些概念单独拿出来，我觉得自己能讲。真把它放进一章里，才发现前面还有一步没交代。

写着写着，我发现自己还挺擅长把复杂的技术讲明白。我喜欢先想想，第一次听到这个概念的人会卡在哪儿。要是一个例子还没讲透，我就换个讲法，把前因后果再捋一遍。开个玩笑，我要是去当老师，肯定挺厉害的。

最后我把书放到了 GitHub 上。我以前从 Rust 社区的开源书和项目里学到了很多。自己卡住的时候，有人已经把那个问题讲明白了，还顺手留了个例子，这种感觉挺好的。我也想留一份这样的东西。以后有人刚开始了解 Internet Computer，可以翻一翻。遇到我讲得含糊或者写错的地方，也可以提出来一起改。《ConstellationBook》

当初答应朋友的其实就一句话，等我整理好发给你。要是那时候我一上来就给自己定个目标，说今年要写一本书，我可能还会纠结半天第一章叫什么。还好当时只是想，先把手头这几页笔记理一理。
