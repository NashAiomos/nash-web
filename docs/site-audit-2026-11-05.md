# 2026-11-05 页面审计与修复

本报告记录本次页面修复的范围、验证结果和仍需外部配置的事项。

## 核实与处理

| 问题 | 结果与修复 |
| --- | --- |
| 桌面目录横向溢出 | 确认定位和固定宽度会越界。目录宽度按正文右侧剩余视口空间计算，长标题可换行，长目录可内部滚动。 |
| 刷新后标题变成路径 | 删除全局路径标题中间件。文章使用正文标题，Blog、Search、Projects、Tags 各自设置标题。 |
| 图片点击监听累积 | 删除 mousemove 绑定，改用一个 document 点击委托，覆盖客户端导航后出现的图片；无需先移动鼠标。 |
| 原图过大 | 207 张独立原图生成 WebP 和 srcset，宽度为 480、960、1440px，不放大低分辨率原图。衍生图随 GitHub Pages 发布，灯箱才请求 R2 原图。 |
| 文章语言错误 | 每篇文章添加 en 或 zh-Hans；正文挂载时设置 html lang，离开文章后恢复站点默认英语。 |
| 替代文本和空说明 | 查看全部 207 张独立图片，为 241 处文章图片引用补充或替换无意义 alt。只有显式提供 caption 才渲染 figcaption。 |
| Back / To Top 键盘不可访问 | 改为原生 button。 |
| 博客列表结构错误 | 年份使用列表外的 h2，每个年份的 ul 直接包含 li，li 包含链接。 |
| /p/ 空页 | 使用 await navigateTo 并显式预渲染。输出含跳往 /nash-web/blog 的 meta refresh；GitHub Pages 不支持应用发出真正的服务端 301。 |
| 失效外链 | 读取 HTTP 状态确认 NeutronStarLab 为 404、旧博客站为 503。前者移除失效超链接并保留文字，后两处文章链接改为站内路径。 |

同时补上 Blog 的 h1、搜索标签、窄屏导航可访问名称；将复制事件移到按钮，并支持焦点/触屏可见；目录高亮保持最近经过的标题；以真实的 /rss.xml 替换占位 RSS，添加订阅链接；年份使用 parseISO 避免纯日期的 UTC 跨年问题。

额外发现《中子星笔记》的标签行在 320px 下溢出，已添加换行。

## 图片体积

武汉篇 84 张原图合计 93,388,491 bytes（89.1 MiB）。对应整篇衍生图：

- 480px 档：2,309,004 bytes（2.2 MiB）。
- 960px 档：5,979,134 bytes（5.7 MiB）。
- 最大 1440px 档：8,700,952 bytes（8.3 MiB）。

浏览器按视口和设备像素比选择一档，不会把三档全部下载。继续使用懒加载。
全站原图去重后 166,562,857 bytes；按文章重复引用累计为 194,040,340 bytes（185.1 MiB），因此原报告的约 185 MB 对应的是重复引用累计口径。

衍生资源约 29 MB（包含全部档位），已纳入工作区。`pnpm images:optimize` 可从本地备份或逐个下载的原图重新生成，并校验 SHA-256。正常构建无需访问 R2。
